# GLAMPING EMPORDÀ

**Capacidad:** 5

**Zona:** 2

**Aire acondicionado:** ✓

**Superfície:** 25 m²

Ubicación

Glamping Empordà está diseñado para ofrecer una experiencia excepcional que combina la aventura del camping con el confort. Cuenta con una cocina completamente equipada para preparar comidas deliciosas, un lavabo con ducha para refrescarse después de un día de actividades al aire libre, y un WC privado para mayor comodidad.

Dentro del alojamiento, encontrarás una acogedora cama doble para descansar cómodamente, así como una habitación con litera donde la parte de abajo es una cama doble, ideal para familias o grupos pequeños. Este ambiente acogedor y bien equipado te permite disfrutar de la naturaleza sin renunciar a las comodidades modernas, haciendo del glamping una opción perfecta para escapadas memorables.

- **Extras contratables:** toallas (precio 7 € + 25 € de depósito reembolsable por pack) y barbacoa
- No se admiten tiendas complementarias ni animales
