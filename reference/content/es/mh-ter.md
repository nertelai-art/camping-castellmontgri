# MH TER

**Capacidad:** 6

**Zona:** 3

**Aire acondicionado:** ✓

**Superfície:** 26 m²

Ubicación

Los MH Ter ofrecen una experiencia de alojamiento cómoda y funcional para familias y grupos pequeños. Consta de una habitación con cama de matrimonio (135×190), una habitación con dos camas individuales (80×190), y una habitación con litera para niños menores de 16 años (60×180).

El alojamiento también incluye un baño completo con ducha y WC para mayor comodidad. La cocina está completamente equipada con horno, nevera espaciosa (145×55) y utensilios de cocina, perfecta para preparar comidas caseras durante la estancia.

Estos alojamientos están diseñados para proporcionar todo lo necesario para una estancia confortable y están ubicados en diferentes zonas del camping para adaptarse a las preferencias de los huéspedes.

- **Extras contratables:** toallas (precio 7 € + 25 € de depósito reembolsable por pack) y barbacoa
- No se admiten tiendas complementarias ni animales
